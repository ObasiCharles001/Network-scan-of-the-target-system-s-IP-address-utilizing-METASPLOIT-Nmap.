# Network-scan-of-the-target-system-s-IP-address-utilizing-METASPLOIT-Nmap.
Analysis Using METASPLOIT for a network scan of the target system’s IP address utilizing Nmap with the -sC, -sV, and -vv options
*Overview:*
The analysis with METASPLIOT was conducted as part of an investigation to detect and identify vulnerabilities in the target systems network. The tool was used to scan the target system IP address and ports in the network utilizing Nmap with the -sC, -sV, and -vv options.
